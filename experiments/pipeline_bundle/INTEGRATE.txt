USAGE
-----
    from pipeline import extract_positions, match_positions
    from pipeline import LLMConfig, ExtractConfig, MatchConfig

    llm = LLMConfig(provider="openai", model="gpt-4o-mini")   # or deepseek/openrouter/custom

    positions = extract_positions(pdf_bytes, llm_config=llm, config=ExtractConfig())     # STEP 2
    matched   = match_positions(positions, catalog, llm_config=llm, config=MatchConfig()) # STEP 3

    # feed straight into your pricing engine (step 4)
    import numpy as np, pandas as pd
    df = pd.DataFrame(matched)
    df["include"] = True                    # reviewer column, your project owns it
    df["custom_unit_cost_chf"] = np.nan
    calc = calc_positions(df, catalog, productivity, sim)

WHY engine/ IS IN HERE
----------------------
The pipeline imports engine/ ONLY as a fallback:

  step2_extract.py  ->  engine.parser.parse_tender     (when Docling is absent)
  step3_match.py    ->  engine.matcher.match_position  (when the LLM is off / fails)

So if you ship Docling + an API key and never want the fallback, you can delete
those imports -- but they are the safety net that keeps the pipeline running when
a call fails, so keeping them is recommended.

The full API reference, the integration contract, and the enforced guardrails are
in pipeline/README.md.
